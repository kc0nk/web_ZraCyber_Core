# ZraCyber-Core Portfolio

Portofolio satu halaman, responsif, dan berbahasa Indonesia. Buka `index.html` di browser untuk melihat situs.

## Isi data proyek

- Di `script.js`, isi `RELEASE_LINKS.apk` dengan URL APK dan `RELEASE_LINKS.github` dengan URL repositori. Tombol unduhan akan membuka URL tersebut.
- Di `index.html`, ganti `Tambahkan nama pembuat`, teks profil, dan kartu riwayat dengan data yang benar.
- Ganti elemen `Foto pembuat` dengan foto, dan desain sertifikat contoh dengan foto sertifikat asli. Kartu saat ini hanya contoh tata letak, bukan klaim pencapaian.
- Logo yang diberikan tersimpan di `assets/zracyber-core-logo.png`.
